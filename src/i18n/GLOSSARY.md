# Translation glossary

Use these terms consistently. Spanish is neutral Latin American (usted-free, informal "tú" voice like the
English UI). Japanese uses polite plain UI style (です/ます in sentences, noun-style labels on buttons),
katakana for established gaming loanwords. French is France/international French with the polite "vous"
form; page names as the app shows them (Accueil, Entrée, Mouvement, Vibrations, Sans fil, Manette, Arène)
and a normal space before : ; ? ! **All translations are drafts pending native review.**

Keep untranslated: product names (HHL Gamepad Config, HOJA, Hand Held Legend, GC Ultimate, ProGCC…),
button names printed on hardware (A, B, X, Y, L, R, ZL, ZR, Start, Select, Home, BOOTSEL), file/drive names
(RPI-RP2, RP2350, UF2, INFO_UF2.TXT), mode names that are brands (Switch, XInput, Steam, Slippi,
GameCube, N64, SNES — the UI says "Steam" for the firmware's SInput mode), units, and `{placeholders}`.
